This release is about building the app from source anywhere, not just on my machine.

The Gradle properties had my local JDK path baked in, which meant the project only compiled on Windows with that exact JDK installed - every other machine, including F-Droid's build servers, failed immediately. That line is gone; Gradle now uses whatever JDK it is run with.

The memory limit for the Gradle JVM is also lower, so the build fits on smaller CI machines without being killed.

No functional changes, and your notification history is untouched. The version number moves to 1.3 so this build can be offered as an update.
